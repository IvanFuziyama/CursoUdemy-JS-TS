# Curso de JavaScript e TypeScript — do básico ao avançado

Curso completo de JavaScript e TypeScript, abrangendo desenvolvimento **Front-end, Back-end e Full Stack**.

Entre os principais conteúdos estudados estão:

- **JavaScript**
- **TypeScript**
- **Node.js**
- **Express**
- **NoSQL**
- **React**
- **Hooks**
- **Redux**
- **Design Patterns**
- **Desenvolvimento Front-end e Back-end**
